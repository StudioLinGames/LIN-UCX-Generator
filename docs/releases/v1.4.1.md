# v1.4.1 — LIN UCX Generator

**Less time creating collisions. More time creating games.**

Studio Lin Games approves 1.4.1 as a stable-publication candidate with known geometric
limitations. This release improves supporting-plane diagnostics, separates convexity
from source containment, and adds validated double-precision reconstruction when
native/regularized hull generation fails. The normalized acceptance tolerance remains
`2e-6`; there is no per-asset exception or automatic fallback box.

Includes seven collision methods, editable native Decimate simplification, evaluated
statistics, safe management and Select Asset + Collisions for FBX selection.
Verified on Windows Blender 5.2.2 LTS / 5.3.0. Other platforms and Blender 4.2 are
unverified. Owner-reported production Unreal tests include Native Box and player
passage through a segmented arch; these are not automated engine tests.

Known limits: open/non-manifold or complex segmentation inputs may be rejected.
Very small open synthetic barrel cases remain safely rejected in original automated
records (198/200 passed). Manual seed 3006 later succeeded while seed 3009 still
failed; no automated result was changed. Simplification warnings require review.
See docs/known_limitations.md.
